# ElectroPlate — Downloads & Releases

Official installers and auto-update feeds for **ElectroPlate** — describe the
app in plain English and get a real, custom desktop application on your own
computer. No SaaS fees; your data stays local.

🌐 **Website:** https://godsonj64.github.io/electroplate-releases/

➡️ **[Download the latest release](https://github.com/godsonj64/electroplate-releases/releases/latest)**

| Platform | File |
|----------|------|
| macOS (Apple Silicon & Intel) | `ElectroPlate-*-universal.dmg` |
| macOS (Apple Silicon & Intel), archive | `ElectroPlate-*-universal-mac.zip` |
| Windows 10/11 (x64) | `ElectroPlate-Setup-*.exe` |

Installed copies update themselves from this channel. Installers are currently
unsigned — macOS Gatekeeper and Windows SmartScreen may warn on first launch
(open anyway).
